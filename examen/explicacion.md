# Explicación del Proyecto

El proyecto consiste en desarrollar "Portal de Servicios" utilizando Flask, HTML, CSS y Bootstrap. El objetivo principal fue poner en desarrollo aplicaciones web dinámicas mediante el uso de rutas, plantillas y formularios que interactúan con el servidor.

La página principal funciona como punto de acceso a las diferentes secciones del sistema. Además, incluye un carrusel de imágenes que brinda una apariencia más moderna

se implementaron herramientas de cálculo que procesan información de formularios HTML utilizando el método POST

Las compras permite obtener el subtotal de una compra y aplicar descuento del 10% cuando supera los $1,000

La calculadora de salario ayuda a determinar el sueldo de un trabajador tomando en cuenta las horas laboradas y el pago por hora. También considera horas extras, las cuales son pagadas al doble cuando se exceden las 40 horas de trabajo

el conversor de temperatura recibe una cantidad en grados Celsius y muestra de forma automática en Fahrenheit y Kelvin, permitiendo realizar conversiones rápidas entre distintas escalas de temperatura

El sistema también incluye una sección de empresa donde se presenta información institucional, así como la misión y visión de una compañía ficticia

 De igual manera, se desarrolló una sección de servicios utilizando tarjetas Bootstrap acompañadas de imágenes representativas de cada servicio ofrecido

Finalmente, se incorporó una sección de contacto donde se muestran distintos medios de comunicación para que los usuarios puedan localizar fácilmente a la empresa

En conclusión, este proyecto integra conocimientos de programación en Python, desarrollo web con Flask, diseño de interfaces con Bootstrap y manejo de formularios HTML. El resultado es una aplicación funcional, organizada y visualmente agradable que combina contenido informativo con herramientas de cálculo útiles para el usuario.
