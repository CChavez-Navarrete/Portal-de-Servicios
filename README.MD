# Portal de Servicios

## Descripción

Portal de Servicios es una aplicación web desarrollada con Flask y Bootstrap que permite a los usuarios consultar información de una empresa ficticia y realizar diferentes cálculos mediante formularios interactivos.

El sistema incluye tres calculadoras desarrolladas en Python que procesan información enviada mediante formularios HTML utilizando el método POST. Además, cuenta con una interfaz moderna y responsiva construida con Bootstrap, un carrusel de imágenes, sección de servicios, información empresarial y datos de contacto.

---

## Funcionalidades

- Página de inicio con presentación del proyecto.
- Carrusel de imágenes informativas.
- Cálculo de compras con descuento automático.
- Cálculo de salarios considerando horas extras.
- Conversión de temperatura de Celsius a Fahrenheit y Kelvin.
- Información de la empresa, misión y visión.
- Catálogo de servicios mediante tarjetas Bootstrap.
- Página de contacto con información empresarial.
- Diseño responsivo y profesional.
